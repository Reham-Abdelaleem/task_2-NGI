# Creative Academy

A simple landing page for a technology learning academy, built with HTML and CSS. It includes a hero section, a list of popular courses, and a footer.

## Features

- Navigation bar with links to Home, Courses, and About
- Hero section with a call-to-action button
- Course cards: Web Development, UI/UX Design, and Data Science
- Responsive-friendly layout with hover effects on cards and buttons

## Built With

- HTML5
- CSS3

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Reham-Abdelaleem/task_2-NGI.git
   ```
2. Open `index.html` in your browser.
